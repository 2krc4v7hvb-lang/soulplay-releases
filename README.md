# SoulPlay Agent — releases

Update feed and downloads for the SoulPlay Agent, a macOS menu-bar app.

The application source is not in this repository. This repo exists to host
the Sparkle appcast and the notarised disk images it points at.

## Install

Download the latest `.dmg` from [Releases](../../releases) and drag
**SoulPlay Agent** to Applications. The app is signed with a Developer ID
certificate and notarised by Apple, and updates itself from `appcast.xml`
in this repository.

Universal binary — runs on both Apple Silicon and Intel Macs.
